# glitterDE
A customisable but pretty desktop environment :3

## Apps
- **SparkFiles** – file manager
- **SparkTerm** – terminal
- **SparkSettings** – settings
- **SparkCode** – code editor: folder sidebar, tabs, syntax highlighting for ~20 languages (built in, no extra libraries), find/replace, `Ctrl+P` quick open. Run `sparkcode [folder|file[:line]]`.
